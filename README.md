# 📚 Story Book Library

## About the Project

Story Book Library is a simple web application designed to display
information about popular storybooks.

The home page contains a list of books with their images, authors,
genres and prices. When the user clicks the **View Book** button,
the detailed information about that particular book is displayed
on a separate page.

## 📖 Books Included

- Cinderella
- Alice's Adventures in Wonderland
- The Little Prince
- Peter Pan

## ✨ Features

- Book list on the home page
- Book cover images
- Author and genre information
- Book price
- Separate page for each book
- Detailed book information displayed in a table
- Story description
- Navigation back to the home page
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
